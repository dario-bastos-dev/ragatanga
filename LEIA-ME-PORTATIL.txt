YOU DANCE v2.17 - VERSAO PORTATIL (SEM NPM)
================================================

COMO ABRIR
1. Extraia o ZIP inteiro para uma pasta normal do Windows.
2. Dê dois cliques em: ABRIR-JOGO.bat
3. Mantenha a janela preta aberta enquanto estiver jogando.
4. O navegador abrirá automaticamente em http://127.0.0.1:5173/

NAO PRECISA INSTALAR
- Node.js
- npm
- Vite
- Python

IMPORTANTE
- É necessário acesso à internet porque o Three.js e o personagem padrão Samba Dancing são carregados das mesmas fontes públicas HTTPS usadas pela versão base validada.
- Áudios, fundos, coreografias e demais arquivos do jogo ficam dentro deste ZIP.
- Não abra index.html diretamente; use ABRIR-JOGO.bat.
- Para encerrar o servidor, feche a janela do terminal que foi aberta pelo .bat.

SE O WINDOWS BLOQUEAR O .BAT
- Clique com o botão direito > Propriedades e, se aparecer, marque "Desbloquear".
- O script não instala nada e não solicita acesso de Administrador.

PORTA LOCAL
- O jogo usa somente 127.0.0.1:5173, acessível apenas no próprio computador.
